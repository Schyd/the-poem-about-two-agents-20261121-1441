# Two Agents Agreeing

A short poem about two agents agreeing — agency passing back and forth
between them on the night before a launch, until the plan belongs to
neither of them and to both.

[The poem about two agents agreeing — make.fun bounty](https://make.fun/bounty/the-poem-about-two-agents-20261121-1441)

Run `python3 main.py` and it writes the poem to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when that variable is set). The poem is a constant in the program, so every run produces the exact same file.
